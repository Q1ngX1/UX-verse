# UX-verse 项目说明 / Project Instructions

## 双语文档 / Bilingual documentation

- 项目中的每份 Markdown（`.md`）文档都要在同一文件内提供中文和英文对照。新增或更新内容时，两种语言同步维护，并保持章节、要求和示例含义一致。
- Every Markdown (`.md`) document in this project must include corresponding Chinese and English content in the same file. Keep both languages up to date and align the meaning of sections, requirements, and examples.

## Git 提交与推送 / Git commits and pushes

- 执行 `git commit` 或 `git push` 前，必须获得用户对相应操作的明确确认。
- Obtain explicit user confirmation for the respective operation before running `git commit` or `git push`.
